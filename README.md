# Car Rental Management System

A relational database management system developed using MySQL for managing car rentals, customers, bookings, payments, inspections, and maintenance records.

## Features
- Customer Management
- Car Booking System
- Payment Tracking
- Vehicle Maintenance Records
- Inspection Reports
- Multiple Branch Support
- SQL Views for Reports

## Technologies Used
- MySQL
- SQL
- Database Design
- ER Modeling

## Database Concepts Used
- Primary Keys
- Foreign Keys
- Constraints
- Normalization (3NF)
- Views
- Relational Schema

## Tables
1. Branch
2. Customer
3. Car
4. Employee
5. Booking
6. Payment
7. Maintenance
8. Inspection
